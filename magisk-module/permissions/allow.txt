# Permisos "privileged" que el módulo concede a Nexus (app.nexus.launcher).
# Uno por línea; '#' es un comentario.
#
# Con esta lista y los permisos que pide el APK, .github/scripts/build-magisk-module.sh genera
# system/product/etc/permissions/privapp-permissions-nexus.xml:
#   - en esta lista Y lo pide el APK        -> <permission>       (se concede)
#   - en not-privileged.txt                  -> no aparece en el XML (normales y peligrosos)
#   - cualquier otra cosa que pide el APK    -> <deny-permission>  (se deniega)
#
# Cada permiso privilegiado que pide un priv-app tiene que quedar concedido o denegado: si no
# aparece en ningún sitio es una violación de la lista blanca y Android 9+ puede negarse a
# arrancar. Por eso lo que no se concede se deniega de forma explícita en vez de omitirlo.
#
# Los permisos son los que Nexus declara en quickstep/AndroidManifest.xml. Android solo concede
# de verdad los que, en tu ROM, tienen el nivel privileged (o recents); lo que haya concedido
# realmente lo informa RootSystemManager.

# remotas (RemoteAnimationAdapter / RemoteTransition).
android.permission.START_TASKS_FROM_RECENTS
